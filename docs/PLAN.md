# Fix Compilation Errors: Update tinywasm/fmt and tinywasm/mcp API Usage

## Context

The `appointment-booking` module fails to compile and tests cannot run because:

1. **`tinywasm/fmt` v0.18.18** does not have the `FieldDB` type or the `DB` field on `Field`.  
   The generated `model_orm.go` was produced by a newer `ormc` that targets `fmt >= v0.22.x`.
2. **`tinywasm/mcp` v0.0.20** had a builder-based API (`mcp.NewTool`, `mcp.WithString`, `mcp.AddTool(tool, handler)`, etc.)  
   The current API (`v0.1.x`) replaced all of that with a plain `Tool` struct and a `ToolProvider` interface.
3. **`tinywasm/orm` v0.3.2** is behind latest `v0.6.0` — update to keep consistent with fmt/mcp.

No logic changes are required. The service layer, repository layer, FSM, and models are all correct.

## Stage 1 — Fix `model_orm.go` (auto-generated file)

**File**: `model_orm.go`

This file is marked `// DO NOT EDIT. generated by github.com/tinywasm/orm`.  
The correct fix is to **re-run the code generator** after updating the fmt dependency.

### Option A — Re-run ormc (preferred)

```bash
go install github.com/tinywasm/orm/cmd/ormc@latest
ormc
```

This regenerates `model_orm.go` using the current `ormc` and the updated `tinywasm/fmt` API.

### Option B — Manual patch (if ormc is unavailable)

The error is that `fmt.FieldDB` and the `DB` field on `fmt.Field` do not exist in v0.18.18.  
After updating `go.mod` to `fmt v0.22.2`, the existing code in `model_orm.go` is already correct — `DB *FieldDB` exists in v0.22.x. **No code edits needed in this file**, just update go.mod.

**Current code (already correct for v0.22.2):**
```go
var _schemaEmployeeServiceConfig = []fmt.Field{
    {Name: "id", Type: fmt.FieldText, DB: &fmt.FieldDB{PK: true}},
    ...
}
```

This compiles fine once `go.mod` uses `fmt v0.22.2`.

## Stage 2 — Rewrite `mcp.go`

**File**: `mcp.go`

### What changed in tinywasm/mcp v0.1.x

| Old API (v0.0.x) | New API (v0.1.x) |
|------------------|------------------|
| `mcp.Tool(name, opts...)` | removed |
| `mcp.NewTool(name, opts...)` | removed |
| `mcp.WithDescription(...)` | removed |
| `mcp.WithString(...)`, `mcp.WithNumber(...)`, `mcp.WithBoolean(...)` | removed |
| `mcp.Required()`, `mcp.Description(...)` | removed |
| `*mcp.MCPServer` | renamed to `*mcp.Server` |
| `s.AddTool(tool, func(ctx, req) (*Result, error))` | `s.AddTool(tool Tool) error` — handler is inside Tool |
| `mcp.CallToolRequest` / `mcp.CallToolResult` | removed |
| `mcp.NewToolResultError(msg)` | `&mcp.Result{IsError: true, Content: msg}` |
| `mcp.NewToolResultText(msg)` | `mcp.Text(msg)` |
| `mcp.NewMCPServer(name, version)` | `mcp.NewServer(mcp.Config{...}, providers)` |

### New Tool struct

```go
type Tool struct {
    Name        string
    Description string
    InputSchema string // JSON schema string (optional; generated by ormc from model tags)
    Resource    string // required — RBAC resource identifier
    Action      byte   // required — 'c', 'r', 'u', 'd'
    Execute     func(ctx *context.Context, req Request) (*Result, error)
}
```

The `Request` type:
```go
type Request struct {
    Params callToolParams // Params.Arguments is a JSON string
    Action byte
}
```

To decode arguments from `Request`, use `json.Unmarshal` on `[]byte(req.Params.Arguments)` into a `map[string]any`, or define a typed struct and use `req.Bind(target)` if the struct implements `fmt.SafeFields`.

### New ToolProvider interface

The `Register` function must be replaced with a type that implements `ToolProvider`:

```go
type ToolProvider interface {
    Tools() []Tool
}
```

### Result helpers

```go
// Success
return mcp.Text("message"), nil         // wraps text into *Result

// Error
return &mcp.Result{IsError: true, Content: "error message"}, nil
```

func decodeArgs(req mcp.Request) (map[string]any, error) {
    var args map[string]any
    if err := json.Unmarshal([]byte(req.Params.Arguments), &args); err != nil {
        return nil, err
    }
    return args, nil
}

func errResult(msg string) *mcp.Result {
    return &mcp.Result{IsError: true, Content: msg}
}

func (p *ReservationProvider) createReservation(ctx *context.Context, req mcp.Request) (*mcp.Result, error) {
    args, err := decodeArgs(req)
    if err != nil {
        return errResult("invalid arguments"), nil
    }
    cmd := CreateReservationCmd{
        TenantID:                str(args, "tenant_id"),
        ClientID:                str(args, "client_id"),
        CreatorUserID:           str(args, "creator_user_id"),
        EmployeeServiceConfigID: str(args, "employee_service_config_id"),
        SlotStartUTC:            i64(args, "slot_start_utc"),
        Notes:                   str(args, "notes"),
        RescheduledFromID:       str(args, "rescheduled_from_id"),
    }
    res, err := p.svc.CreateReservation(ctx.Std(), cmd)
    if err != nil {
        if errors.Is(err, ErrSlotTaken) {
            return errResult("The selected time slot is already taken"), nil
        }
        return errResult(err.Error()), nil
    }
    b, _ := json.Marshal(res)
    return mcp.Text(string(b)), nil
}

func (p *ReservationProvider) getReservation(ctx *context.Context, req mcp.Request) (*mcp.Result, error) {

## Stage 3 — Rewrite `tests/mcp_test.go`

**File**: `tests/mcp_test.go`

The test uses removed APIs:
- `mcp.NewMCPServer(name, version)` → `mcp.NewServer(mcp.Config{...}, providers)`
- `mcp.NewInProcessClient(s)` → does not exist in v0.1.x; use HTTP round-trip via `s.HandleMessage`
- `mcp.CallToolRequest` / `mcp.CallToolParams` / `mcp.InitializeRequest` → removed
- `res.Content[0].(mcp.TextContent).Text` → `res.Content` is now a string

### New test pattern (v0.1.x)

The server exposes `HandleMessage(ctx, body []byte) JSONRPCMessage`. Use that directly in tests:

```go
package tests

import (
    "testing"

    ab "github.com/veltylabs/appointment-booking"
    "github.com/tinywasm/context"
    "github.com/tinywasm/json"
    "github.com/tinywasm/mcp"
)

type mockService struct {
    ab.SchedulingService
    errToReturn error
}

func (m *mockService) UpsertWeeklyCalendar(ctx context.Context, cal ab.WorkCalendarWeekly) error {
    if cal.StaffID == "" {
        return ab.ErrCalendarConfigNotFound
    }
    return m.errToReturn
}

func (m *mockService) CreateReservation(ctx context.Context, cmd ab.CreateReservationCmd) (ab.Reservation, error) {
    if cmd.SlotStartUTC == 1712000000 {
        return ab.Reservation{}, ab.ErrSlotTaken
    }
    return ab.Reservation{ID: "new-id"}, m.errToReturn
}

func newTestServer(t *testing.T, svc ab.SchedulingService) *mcp.Server {
    t.Helper()
    srv, err := mcp.NewServer(mcp.Config{
        Name:    "test",
        Version: "1.0.0",
        Auth:    mcp.OpenAuthorizer(),
    }, []mcp.ToolProvider{
        ab.NewCalendarProvider(svc),
        ab.NewReservationProvider(svc),
    })
    if err != nil {
        t.Fatalf("NewServer: %v", err)
    }
    return srv
}

func callTool(t *testing.T, srv *mcp.Server, name string, argsJSON string) *mcp.Result {
    t.Helper()
    var ctx context.Context
    body := []byte(`{"jsonrpc":"2.0","id":"1","method":"tools/call","params":{"name":"` + name + `","arguments":` + argsJSON + `}}`)
    resp := srv.HandleMessage(&ctx, body)
    // decode Result from the response
    var envelope struct {
        Result mcp.Result
    }
    encoded := encodeResponse(resp)
    json.Decode([]byte(encoded), &envelope)
    return &envelope.Result
}

func TestMCPHandlers(t *testing.T) {
    svc := &mockService{}
    srv := newTestServer(t, svc)

    t.Run("upsert_weekly_calendar_no_config", func(t *testing.T) {
        res := callTool(t, srv, "upsert_weekly_calendar", `{"tenant_id":"t1","staff_id":"","day_of_week":1,"work_start":540,"work_finish":1020,"break_start":0,"break_finish":0,"is_active":true}`)
        if !res.IsError {
            t.Fatal("expected error result")
        }
        if res.Content != "Set the staff timezone first using upsert_calendar_config" {
            t.Fatalf("unexpected error message: %s", res.Content)
        }
    })

    t.Run("create_reservation_slot_taken", func(t *testing.T) {
        res := callTool(t, srv, "create_reservation", `{"tenant_id":"t1","client_id":"c1","creator_user_id":"u1","employee_service_config_id":"esc1","slot_start_utc":1712000000}`)
        if !res.IsError {
            t.Fatal("expected error result")
        }
        if res.Content != "The selected time slot is already taken" {
            t.Fatalf("unexpected error message: %s", res.Content)
        }
    })
}
```

If unexported, trigger tool calls via `callTool` helper that builds a raw JSON-RPC request body and sends it to the server's HTTP handler instead, using `httptest.NewRecorder`.
