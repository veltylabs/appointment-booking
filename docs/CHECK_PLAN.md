# Fix Standard-Library Imports in mcp.go and tests/mcp_test.go

## Problem

`mcp.go` and `tests/mcp_test.go` import three standard-library packages that are
**forbidden** in this module (WASM-compatibility rule from SKILL.md):

| Forbidden import | Reason |
|---|---|
| `"encoding/json"` | Use `github.com/tinywasm/json` only |
| `"errors"` | Sentinels created with `fmt.Err` are comparable — use `==` |
| `stdFmt "fmt"` | Use `github.com/tinywasm/fmt` only |

No logic changes are required. This is a pure import/API-surface migration.

---

## tinywasm API reference

### `github.com/tinywasm/json`

```go
func Decode(input any, data fmt.Fielder) error
func Encode(data fmt.Fielder, output any) error
```

> **Critical constraint:** both functions require the target/source to implement
> `fmt.Fielder` (i.e. `Schema() []fmt.Field`).  
> `map[string]any` does **not** implement `fmt.Fielder`.  
> This means `decodeArgs` cannot be a simple `Unmarshal` replacement — see Stage 1.

### `github.com/tinywasm/fmt`

```go
func Sprintf(format string, args ...any) string  // replaces fmt.Sprintf
func Printf(format string, args ...any)          // replaces fmt.Printf
func Err(msgs ...any) *Conv                      // sentinel errors
func Errf(format string, args ...any) *Conv      // formatted sentinel errors
```

### Sentinel error comparison

Errors created with `fmt.Err(...)` are `*Conv` pointer singletons declared at package
level. They are comparable with `==`:

```go
// BEFORE (stdlib errors)
if errors.Is(err, ErrSlotTaken) { … }

// AFTER (tinywasm — direct pointer equality)
if err == ErrSlotTaken { … }
```

This is safe because the service layer returns sentinels directly (no wrapping).

## Stage 1 — Fix `mcp.go`

### 1.1 Replace `decodeArgs` with per-tool typed arg structs

`tinywasm/json.Decode` requires `fmt.Fielder`. Instead of decoding into
`map[string]any`, define a lightweight typed struct per tool and use `req.Bind`:

```go
// mcp.Request provides:
func (r Request) Bind(target fmt.SafeFields) error
```

`fmt.SafeFields` extends `fmt.Fielder`, so the arg struct must implement
`Schema() []fmt.Field` and `Pointers() []any` (same as any ORM model).

**Example — `create_reservation` arg struct:**

```go
type createReservationArgs struct {
    TenantID                string
    ClientID                string
    CreatorUserID           string
    EmployeeServiceConfigID string
    SlotStartUTC            int64
    Notes                   string
    RescheduledFromID       string
}

var createReservationArgs_ = struct{ … }{ … } // meta struct generated by ormc

func (a *createReservationArgs) ModelName() string      { return "create_reservation_args" }
func (a *createReservationArgs) Schema() []fmt.Field    { return _schemaCreateReservationArgs }
func (a *createReservationArgs) Pointers() []any        { return []any{&a.TenantID, …} }
func (a *createReservationArgs) Validate(byte) error    { return nil }
```

Then in the handler:

```go
func (p *ReservationProvider) createReservation(ctx *context.Context, req mcp.Request) (*mcp.Result, error) {
    var args createReservationArgs
    if err := req.Bind(&args); err != nil {
        return errResult("invalid arguments"), nil
    }
    cmd := CreateReservationCmd{
        TenantID:                args.TenantID,
        …
    }
    …
}
```

> **Option B (simpler, no Bind):** keep `decodeArgs` but decode the raw JSON string
> with a helper that manually parses key-value pairs via `tinywasm/fmt` string
> utilities. Recommended only if ormc generation is unavailable.

### 1.2 Replace response marshaling

Response structs (`Reservation`, `[]Reservation`, `[]TimeSlot`, etc.) implement
`fmt.Model` which satisfies `fmt.Fielder`. Use `tinywasm/json.Encode`:

```go
// BEFORE
b, _ := json.Marshal(res)
return mcp.Text(string(b)), nil

// AFTER — Encode into a string builder
var buf fmt.Builder
if err := tinyjson.Encode(res, &buf); err != nil {
    return errResult(err.Error()), nil
}
return mcp.Text(buf.String()), nil
```

> **Note:** `json.Encode` only serializes fields listed in `Schema()`. Verify that
> all fields relevant to the MCP caller are declared in the model's schema.

### 1.3 Replace `errors.Is` with `==`

```go
// BEFORE
if errors.Is(err, ErrSlotTaken) {

// AFTER
if err == ErrSlotTaken {
```

Apply to both `ErrSlotTaken` and `ErrCalendarConfigNotFound`.

### 1.4 Replace `stdFmt "fmt"` with `tinywasm/fmt`

```go
// BEFORE
import stdFmt "fmt"
…
return mcp.Text(stdFmt.Sprintf("Expired %d reservations", count)), nil

// AFTER
import "github.com/tinywasm/fmt"
…
return mcp.Text(fmt.Sprintf("Expired %d reservations", count)), nil
```

### 1.5 Final import block for `mcp.go`

```go
import (
    "github.com/tinywasm/context"
    "github.com/tinywasm/fmt"
    "github.com/tinywasm/json"
    "github.com/tinywasm/mcp"
)
```

## Stage 2 — Fix `tests/mcp_test.go`

The test currently uses `encoding/json` to:
1. Marshal the `srv.HandleMessage` response to bytes.
2. Unmarshal bytes into ad-hoc anonymous structs.

These anonymous structs do **not** implement `fmt.Fielder`, so `tinywasm/json`
cannot replace them directly. The solution is to **test providers directly**
instead of through the server's JSON-RPC layer.

### 2.1 Remove JSON-RPC round-trip — call Execute directly

```go
func callTool(t *testing.T, provider mcp.ToolProvider, name string, argsJSON string) *mcp.Result {
    t.Helper()
    for _, tool := range provider.Tools() {
        if tool.Name != name {
            continue
        }
        ctx := tinyctx.Background()
        req := mcp.Request{}
        req.Params.Arguments = argsJSON
        res, err := tool.Execute(ctx, req)
        if err != nil {
            t.Fatalf("Execute returned error: %v", err)
        }
        return res
    }
    t.Fatalf("tool %q not found", name)
    return nil
}
```

This eliminates the JSON-RPC envelope entirely and removes all
`encoding/json` dependency from the test.

### 2.2 Replace `context` import

The mock service methods signature must match the real `SchedulingService`.
If `SchedulingService` uses `context.Context` from stdlib (via `context_workaround.go`),
keep `"context"` only in the mock. If it uses `*tinyctx.Context`, remove it.

### 2.3 Final import block for `tests/mcp_test.go`

```go
import (
    "testing"

    "github.com/tinywasm/context"
    "github.com/tinywasm/mcp"
    ab "github.com/veltylabs/appointment-booking"
)
```

## Stage 3 — Generate arg structs with `ormc`

`ormc` is designed to generate boilerplate for database tables, but it can also generate `fmt.Fielder` and `fmt.Validator` implementations for plain structs (like our MCP arguments) using the `// ormc:formonly` directive.

1. **Delete any handwritten implementations** (remove `mcp_args.go` if it exists).
2. **Define the structs in** `model.go`.
3. **Add the `// ormc:formonly` directive** immediately above each struct definition.

**Example `model.go` updates:**

```go
package appointmentbooking

// ormc:formonly
type createReservationArgs struct {
    TenantID                string
    ClientID                string
    CreatorUserID           string
    EmployeeServiceConfigID string
    SlotStartUTC            int64
    Notes                   string
    RescheduledFromID       string
}

// ormc:formonly
type getReservationArgs struct {
    TenantID string
    ID       string
}

// ... add the remaining 9 arg structs with the same directive
```

4. **Run `ormc`**

Run the generator from the project root:

```bash
ormc
```

This will automatically generate `model_args_orm.go` with `Schema()`, `Pointers()`, and `Validate()` for the argument structs, without adding any DB-specific operations like `ReadOne()`.

## Stage 3b — Encoding list responses (dependency on library updates)

> **This stage is blocked until `tinywasm/json >= v0.5.0` and `tinywasm/orm >= v0.7.0`
> are released.** Do not work around the limitation with wrapper structs or manual
> string building — that creates technical debt.

### Root cause

`json.Encode` accepts only `fmt.Fielder` (a single struct → JSON object).
Tools that return a list (`ListReservationsByStaff`, `ListAvailability`, etc.)
need to encode a JSON **array** `[...]` at the root — this is not possible today.

### What the library updates will provide

**tinywasm/json v0.5.0** — `Encode` / `Decode` widened to `any`:
```go
func Encode(data any, output any) error   // fmt.FielderSlice → encodes as JSON array
func Decode(input any, data any) error    // fmt.FielderSlice → decodes from JSON array
```
No new public functions — the right format is chosen internally based on type.

**tinywasm/orm v0.7.0** — `ormc` will generate for every DB-backed struct:
```go
type ReservationList []*Reservation

func (s *ReservationList) Len() int             { return len(*s) }
func (s *ReservationList) At(i int) fmt.Fielder { return (*s)[i] }
func (s *ReservationList) Append() fmt.Fielder  { v := &Reservation{}; *s = append(*s, v); return v }
```
`ReadAllReservation` return type changes from `([]*Reservation, error)` to `(*ReservationList, error)`.

### How to use after update

Bump `go.mod` to the new versions and run `ormc` to regenerate `model_orm.go`.
Then encode list results with:

```go
rows, err := ReadAllReservation(qb)
if err != nil { ... }

var out string
if err := json.EncodeArray(rows, &out); err != nil {
    return errResult(err.Error()), nil
}
return mcp.Text(out), nil
```

`rows` is `*ReservationList` which implements `fmt.FielderSlice` — pass it directly,
no wrapper needed.

### ReadAll* call-site change

All `ReadAll*` results previously typed as `[]*{Name}` become `*{Name}List`.
Range loops change from `for _, r := range rows` to `for _, r := range *rows`
(dereference once). Indexing: `(*rows)[i]` or `rows.At(i)`.
